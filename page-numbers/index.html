Page numbers — questions

Can the numbering start at a number other than 1?

Yes. Set the starting number to anything from 0 to 9999 — useful when your document is part of a larger set, or the first page is a cover.

Will the numbers overlap my content?

The numbers are placed in the margin areas — bottom center, bottom right or top right — well away from the main content. If a page has its own footer, pick a different position.

Does numbering change the file quality?

No. Only the number text is added to each page; the original content is untouched.
